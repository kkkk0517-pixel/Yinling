# Issue #8：L1 采集与每日聚合实施计划

> 阶段记录：下文保留该阶段完成时的状态；当前整体复核、最新测试与提交评审事项见 [#8–#12整体复核](2026-11-05-c-engine-pr-review.md)。

**目标**：满足 #8 的三项验收：打卡写入事件、切日聚合、唯一键幂等。

**已批准方案**：沿用现有接口和表结构；E1 采集打开事件，E2 采集日历确认；业务日期按 UTC+8、`day_cut_hour`（默认 4）计算。事件和即时聚合使用同一事务；切日按原始记录重算而非累加，重复执行结果一致。

**范围**：`server/` 的 L1、E1/E2 和可手动调用的 T1。四键及音频元数据、服务完成、关系人成功回执在 T1 从现有业务记录采集，保留来源 ID。不改变业务接口、权限、状态机、数据库结构，不增加依赖。不实现 L2–L4、自动调度、倍速或演示重置；这些分别属于 #9–#12、#25。

**技术**：CommonJS、Express、mysql2、Node.js 20+ 内置 `node:test`、MySQL 8.0。
