## 一、分工原则：按"纵切"分，不按前后端分

三个人各自端到端负责一块业务（页面 + 接口 + 数据），而不是"一个人写前端、一个人写后端"。

**理由有三条：**

1. **前后端分离在 3 人规模下会互相等。** 前端等接口、后端等联调，中间空转的时间比写代码还长。
2. **纵切的人对自己那块业务最清楚**，不用来回解释"这个字段为什么这么设计"。
3. **谁的模块谁修 bug**，不会出现"这个不知道归谁"。

代价是：**接口契约必须先定死**（已经出了 `docs/04-接口列表.md`），否则三个人各写各的，联调时全推倒。

## 二、三个人的包

### A｜居民侧（老人端 + 关系人端）

**页面 9 个**：老人端 P0 日历弹窗、P1 首页、P2 录音、P3 回执、P4 日历册；关系人端 R-01 我的老人、R-02 今日卡片、R-04 服务单/账单

**接口 21 个**：`A1–A5`（与 C 合做）、`E1–E7`、`R1–R9`

**技术要点：**

- 微信小程序（原生），一个包按 `functions` 分流到两个端
- 录音：`wx.getRecorderManager` + `wx.uploadFile`，格式 mp3，16kHz 单声道
- 本地缓存：上传失败的音频存 `wx.setStorage`，联网重传
- 适配老化：字号 ≥18px、按钮 ≥64px、不用滑动/双击

**难点**：老人端是全项目交互最细的一块，规格文档有 370 行，别自己简化。

### B｜社区侧（处置端 + 管理端）

**页面 9 个**：H-01 工作台、H-02 核验单详情、H-03 处置结论、H-04 服务单；M-01 总览、M-02 老人列表、M-04 关系链编辑器、M-07 参数、M-08 工单列表

**接口 21 个**：`H1–H10`、`M1–M11`

**技术要点：**

- 处置端：响应式 H5（手机浏览器），**单页，不做导航**
- 管理端：桌面 Web，Vue 3 + Element Plus 或 React + Ant Design（用熟的）
- 关系链编辑器是本块最重的组件：拖拽加层、加人、指定主责、设时限
- 总览只做 4 个数字 + 一句口径说明，**不做图表**

**难点**：H-03 处置结论必须 15 秒能填完，表单字段多一个都会拖慢。B 自己拿手机计时试。

### C｜引擎与数据

**没有页面**（演示开关的 UI 归 B，接口归 C）

**负责：**

| 模块 | 内容 |
|---|---|
| 数据库 | 建表、索引、种子数据（`docs/05-数据表DDL.md`） |
| 认证 | JWT 签发/校验中间件、`functions` 权限拦截 |
| L1 采集 | 埋点写入、每日聚合到 `signal_daily` |
| L2 基线 | 近 14 天中位数 + MAD，冷启动输出"信息不足" |
| L3 分层 | D × Q 四格，写 `alert` + `signal_snapshot` |
| L4 路由 | 分层通知、SLA 计时、CAS 升级、紧急单全链广播 |
| 定时任务 | T1 切日 / T2 SLA 扫描 / T3 基线 / T4 分层 |
| 演示 | `D1–D3`：重置、手动触发、时间倍速 |

**技术要点：**

- SLA 扫描**必须用 CAS**（`UPDATE ... WHERE current_layer = ?`），先查后改会重复升级
- 时间倍速只改一个 `now()` 函数，不要散在每个任务里
- 所有"创建类"接口靠唯一键幂等，不靠 if 判断

**难点**：C 这块没有页面，看起来轻松，实际是全项目最难的部分——**机制的"聪明"全在这**。给 C 的时间要留够。

```
W1   C：数据库 + 认证 + 空壳接口 + 种子数据     ← 地基，别人都在等这个
```

## 四、三个最容易拖垮进度的地方

### 4.1 接口契约中途改

**症状**：A 说"这个字段不够用"，C 改了返回结构，B 那边崩了。

**对策**：
- 契约冻结后**只加字段，不改字段、不删字段**
- 真要改，在群里发一句"接口变更：xxx 从 a 改成 b，影响 A/B"，**三个人确认后再动**
- 新增字段一律可选，前端做好缺省

### 4.2 录音（最容易被低估）

小程序录音有四个坑：iOS 格式不兼容、拒绝权限后无法再次弹窗、切后台中断、真机与开发者工具行为不一致。

**对策**：W1 就让 PM 用两台真机（一台 iOS、一台安卓）跑通"录 → 传 → 播"，跑不通就降级成"只建单不录音"，别等到 W4 才发现。

### 4.3 演示当场翻车

**症状**：网络断了、数据被点乱了、定时任务没跑、打开页面是空的。

**对策**：
- `D1 一键重置` 必须在 30 秒内跑完
- 关键路径全部**录屏备份**
- 演示前 10 分钟跑一次 `D1`，确认四个数字都是初始值
