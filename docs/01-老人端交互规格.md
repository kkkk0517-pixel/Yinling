# 银铃 · 老人端交互规格 v0.1

> 范围：老人端（Web/H5 优先，小程序同构）
> 状态：草案，待 kk 确认后冻结
> 日期：2026-10-18

---

## 一、设计原则

| # | 原则 | 具体含义 |
|---|---|---|
| 1 | **一屏到底** | 首页不滚动，所有主操作在首屏可见 |
| 2 | **按钮是陈述，不是求助** | 文案用"买东西/不舒服"，不用"申请代购/我需要帮助"。老人怕麻烦别人，一个"求助"字样就能让他放下手机 |
| 3 | **按钮本身就是信息** | 老人按了键就算表达，不录音也要能建单。录音是增强，不是前提 |
| 4 | **说完必须有回音** | 任何操作后 200ms 内必须有可见反馈。老人说完话没反应，他会以为坏了，然后不再用 |
| 5 | **紧急永远可达** | 红色紧急条常驻底部，任何页面（含弹窗态）都可见、可按 |
| 6 | **不惩罚沉默** | 老人不确认、不录音、不响应，系统不报警、不升级、不催促 |

## 二、页面与状态

### 2.1 页面清单

| 编号 | 页面 | 说明 |
|---|---|---|
| P0 | 启动 + 日历弹窗 | 每日首次打开时覆盖在首页上 |
| P1 | 首页 | 日历条 + 四键 + 紧急条 + 最近探访 |
| P2 | 录音页 | 从四键进入，按住说话 |
| P3 | 回执页 | 提交后的确认与撤回 |
| P4 | 日历册 | 已撕页面的回看 |
| P5 | 求助记录 | 历史单列表（可选，二期） |

### 2.2 全局状态机

```
S0 启动加载
 └→ 今日已确认？ ──是──→ S2 首页
                    └否──→ S1 日历弹窗
                              ├ 撕页/确认 ──→ S2 首页（今日标记已确认）
                              └ 点 ×     ──→ S2 首页（仍为未确认，下次打开再弹）

S2 首页
 ├ 按四键 ──→ S3 录音页 ──→ S4 发送中 ──→ S5 回执 ──→ S2
 ├ 长按紧急 3s ──→ 立即建单 ──→ S5 回执（可继续录音补充）
 ├ 点日历条 ──→ P4 日历册
 └ 点"最近有人来看您" ──→ P5（或展开浮层）
```

### 2.3 关键状态定义

| 状态 | 存储位置 | 重置时机 |
|---|---|---|
| 今日是否已确认 | 服务端 + 本地缓存 | **每日凌晨 4:00**（非 0 点） |
| 弹窗本次是否已关闭 | 内存（刷新即失效） | 页面刷新 |
| 录音中 | 内存 | — |
| 待上传队列 | IndexedDB / 本地文件 | 上传成功后删除 |

> **为什么按 4 点切日**：老人睡眠浅，凌晨 2–3 点起夜开手机很常见。按 0 点切日，他会看到"新的一天"又要撕一次，产生困惑。

## 三、P0 启动与日历弹窗

### 3.1 触发条件

- 应用启动，且 `todayConfirmed == false`
- 页面加载完成后 **延迟 500ms** 再弹（避免盖在加载中的页面上闪烁）

### 3.2 弹窗结构

```
┌─────────────────────────────┐
│  2026 年 10 月          [×] │
│           18                │
│    星期日 · 农历九月初八      │
│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─   │
│  今日宜          今日忌       │
│  晒太阳          久坐不动     │
│  给女儿打电话     一个人爬高   │
│                             │
│  ┌───────────────────────┐  │
│  │  今天挺好，撕下这一页   │  │
│  └───────────────────────┘  │
│        已攒下 12 页          │
└─────────────────────────────┘
     ↓（弹窗不覆盖此处）
┌─────────────────────────────┐
│   不舒服，按住 3 秒           │  ← 常驻，任何状态下可见
└─────────────────────────────┘
```

### 3.3 交互规则

| 操作 | 结果 |
|---|---|
| 点"撕下这一页" | 播放撕纸动效（300ms）→ 弹窗关闭 → 标记今日已确认 → 写 `calendar_confirmed` 信号 → 首页日历条变为"已撕下" |
| 点右上角 × | 弹窗关闭，**不标记确认**。下次打开应用仍会弹 |
| 点弹窗外遮罩 | 同 ×，不标记确认 |
| 长按底部紧急条 | **不受弹窗阻挡**，直接进入紧急流程 |

### 3.4 内容生成规则

- **公历/星期/农历**：本地算法计算，不依赖网络
- **宜/忌内容**：本地 JSON 内容库（建议 100–150 条），按 `月份 + 天气 + 节日` 标签匹配
  - 不做实时 LLM 生成（成本高、不稳定、可能生成不当内容）
  - LLM 仅用于"个性化补充"：根据老人档案的慢病标签追加一条（如高血压 → "记得量血压"），且需人工审核过的模板
- **内容约束**：每条 ≤ 8 字，必须是可执行动作，不出现"祭祀/嫁娶/动土"等传统黄历条目

### 3.5 内容库示例

| 标签 | 宜 | 忌 |
|---|---|---|
| 春·晴 | 出门走走、晒被子 | 早晚贪凉、空腹出门 |
| 夏·高温 | 多喝水、午间小睡 | 正午出门、空调直吹 |
| 秋·干燥 | 喝点汤水、擦润肤霜 | 久坐不动、一个人爬高 |
| 冬·寒 | 泡脚、给老友打电话 | 洗澡太久、地面留水 |
| 通用 | 给女儿打个电话、把药盒理一理 | 一个人搬重物、忘了吃药 |

## 四、P1 首页

### 4.1 布局（自上而下）

| 区域 | 内容 | 高度 |
|---|---|---|
| 顶部 | 日历条（已确认态）或 提示条（未确认态） | 56px |
| 中部 | 四键 2×2 网格 | 自适应 |
| 下部 | 最近探访卡片 | 60px |
| 底部 | 红色紧急条（吸底） | 56px |

### 4.2 顶部条两态

| 状态 | 显示 | 点击 |
|---|---|---|
| 已确认 | `10 月 18 日 · 已撕下` / `宜晒太阳 · 已攒 12 页` / 右侧"看日历册" | 进入 P4 |
| 未确认 | `今天还没撕日历` / 右侧"去撕一页" | 重新弹出 P0 |

### 4.3 四键定义

| 位置 | 键名 | 引导语（弹层，≤15 字） | 录音提示 | 生成单据 |
|---|---|---|---|---|
| 左上 | **买东西** | 您要买什么？按住说 | 我在听，说完松手 | 服务单·代购 |
| 右上 | **不舒服** | 哪儿不舒服？慢慢说 | 我在听，说完松手 | 服务单·健康（可升级核验单） |
| 左下 | **东西坏了** | 什么东西坏了？按住说 | 我在听，说完松手 | 服务单·维修 |
| 右下 | **看病取药** | 要去医院，还是取药？ | 我在听，说完松手 | 服务单·陪诊/取药 |
| 底部 | **紧急**（红条） | 无引导语，长按即建单 | 建单后可选补充录音 | **核验单·紧急** |

> 四键**位置一旦上线不得调整**。老人靠位置记忆，不靠认字。

### 4.4 四键交互流程

```
点击键
  ↓ (150ms 内)
弹出引导层（半屏，底部滑入）
  ├ 显示引导语
  ├ 大按钮："按住说话"
  └ 次要按钮："不想说，直接叫人"
  ↓
按住 → 录音（见第五节）
```

**"不想说，直接叫人"是必备出口**，不是可选项。老人按了键但说不出话、或不想说，必须能一键建单。

### 4.5 紧急条

| 项 | 规格 |
|---|---|
| 位置 | 吸底，`position: sticky`（非 fixed，避免遮挡内容） |
| 外观 | `#A32D2D` 实底，白字 18px，高度 56px，圆角 12px |
| 触发 | 长按 3 秒，环形进度动画 |
| 中途松手 | 取消，无任何后果 |
| 触发后 | **立即建核验单**（不等录音），弹出回执页，同时提供"再说两句"按钮补充描述 |

> 紧急场景下**建单优先于描述**。老人摔倒时说不清话，不能因为等描述而延误。

## 五、P2 录音页

### 5.1 状态机

```
idle
 └ 请求麦克风权限
     ├ 拒绝 → 显示"没开麦克风"，提供"直接叫人"兜底 + 引导开启
     └ 允许 → ready
         └ 按住 → recording
             ├ 松手（≥1s）→ encoding → uploading → done
             ├ 松手（<1s）→ 提示"再多说两句"，回 ready
             ├ 60s 自动停 → encoding → uploading
             └ 中途来电/切后台 → 保留已录部分，暂停
```

### 5.2 录音规格

| 项 | 规格 |
|---|---|
| 最短时长 | 1 秒（不足则提示，不发送） |
| 最长时长 | 60 秒（到点自动停并发） |
| 格式 | Web: `audio/webm;codecs=opus`；小程序: `mp3` 或 `aac` |
| 采样率 | 16kHz 单声道（足够 ASR，体积小） |
| 松手后 | **直接发送，不设倒计时**（倒计时会拖慢主流程） |
| 纠错 | 回执页提供 10 秒内"撤回" |
| 原始音频 | **永久留存，不因撤回而删除**（撤回只撤单，不删证据） |

### 5.3 本地缓存与重传

| 场景 | 处理 |
|---|---|
| 上传中网络断 | 音频存 IndexedDB，标记 `pending`，界面显示"已记录，等有网就发出去" |
| 网络恢复 | 自动重传，最多重试 5 次（指数退避 2s/4s/8s/16s/32s） |
| 重试全失败 | 显示"发送失败，点这里重发"，同时保留本地文件 |
| 页面关闭 | 本地文件保留，下次打开时检查 `pending` 队列并提示 |
| 幂等 | 每次录音生成 `client_request_id`（UUID v4），服务端按此去重 |

### 5.4 防重复提交

- 提交按钮在 `uploading` 期间置灰
- 服务端以 `client_request_id` 为唯一键，重复请求返回已有单据
- 同一老人 30 秒内同类型单据合并（避免老人以为没发出去又按一遍）

## 六、P3 回执页

### 6.1 内容

```
        ┌─────────┐
        │    ✓    │
        └─────────┘
      收到啦
   已经通知到人了
  一般 30 分钟内有人联系您

   [ 再说两句 ]   [ 撤回 ]
```

### 6.2 分级承诺

| 类型 | 承诺话术 | 依据 |
|---|---|---|
| 紧急 | "马上有人来，您别动" | 立即通知全部关系人 |
| 不舒服 / 看病取药 | "一般 30 分钟内有人联系您" | 家属层等待时限 30min |
| 买东西 / 东西坏了 | "今天之内有人联系您" | 服务单可次日处理 |

> **承诺必须兑现**。如果 30 分钟无人响应，系统必须自动升级并给老人推一条"正在帮您找人，别着急"。宁可多说一句，不能让老人等成空。

### 6.3 撤回

- 窗口：10 秒
- 条件：单据尚未被任何人接单
- 结果：单据置为 `cancelled`，音频保留

## 七、P4 日历册

- 纵向列表，每页一张卡片（日期 + 宜忌 + 当天是否有求助）
- 顶部统计："已攒下 12 页 / 连续 8 天"
- 支持回看，不支持编辑
- **不可删除**（这是老人自己的记录，也是系统信号源）

## 九、适老化规范

| 项 | 规格 |
|---|---|
| 正文字号 | ≥ 18px |
| 按钮文字 | 20–24px |
| 触控区 | ≥ 64×64px，间距 ≥ 12px |
| 对比度 | 正文 ≥ 7:1，大字 ≥ 4.5:1 |
| 手势 | **不使用**滑动、双击、长按（紧急键除外） |
| 动效 | ≤ 300ms，支持系统"减少动效" |
| 倒计时 | 不使用（紧急长按除外） |
| 色彩 | 主色 `#1D9E75`，警示 `#A32D2D`，纸底 `#FAF8F2`，正文 `#2C2C2A` |
| 图标 | 不单独使用图标，必须配文字（老人认字强于认图） |

## 十、埋点清单（L1 信号来源）

| 事件 | 字段 | 对应信号 |
|---|---|---|
| `app_open` | ts, source | 弱活动证据 |
| `calendar_popup_shown` | ts | — |
| `calendar_confirmed` | ts | **强确认信号** |
| `calendar_dismissed` | ts | 弱信号（有打开无确认） |
| `button_pressed` | key, ts | 意图信号 |
| `recording_start` | key, ts | — |
| `recording_end` | key, duration, reason | 活跃度 |
| `request_submitted` | type, has_audio, duration, client_id | 需求信号 |
| `request_cancelled` | client_id, reason | 负反馈 |
| `emergency_triggered` | ts, source | **事件型信号，直接建单** |
| `page_view` | page, ts | 弱活动证据 |

> 这些事件同时是行为数据，也是 L1 的证据源。**埋点不是可选项，是系统的一部分。**

## 十一、异常分支矩阵

| 异常 | 处理 | 老人看到 |
|---|---|---|
| 麦克风权限被拒 | 显示兜底按钮 + 引导开启 | 没开麦克风。要不我直接帮您叫人？ |
| 录音 < 1 秒 | 不发送，回 ready | 再多说两句，我听着呢 |
| 录音达 60 秒 | 自动停止并发送 | 说得够啦，我这就发出去 |
| 上传失败 | 本地保留，自动重试 5 次 | 没发出去，点这里再发一次 |
| 完全离线 | 入队，联网自动发 | 已经记下来了，等有网就发出去 |
| 重复提交 | 服务端去重 | 收到啦（不重复提示） |
| 中途来电 | 保留已录部分，暂停 | 继续按住说 |
| 页面被杀 | 本地队列保留，下次打开检查 | 上次有 1 条没发出去，要重发吗 |
| 长按紧急中途松手 | 取消，无副作用 | （无提示） |
| 服务端 5xx | 走离线队列 | 网络不太好，已经记下来了 |
