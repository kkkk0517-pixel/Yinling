# 语音识别开源方案调研

> 调研日期：2026-10-19 ｜ Star 数为当日 GitHub API 实时查询
> 用途：老人端「按住说话 → 识别 → 抽意图」链路的选型依据

---

## 一、结论先行

**不用自己造，也不用只依赖云 API。** 中文 + 粤语的语音识别在开源侧已经成熟，推荐：

> **FunASR 私有部署 SenseVoice-Small 为主，Qwen3-ASR-0.6B 为备选，云 API 只做降级兜底。**

理由三条：
1. 粤语有实测支持（SenseVoice 在粤语上报告约 92.7% 准确率，需自行复测）
2. **MIT / Apache-2.0 许可**，商用和改造都没有法律障碍
3. **可以私有部署**——老人语音属于敏感个人信息，音频不出本地，这跟项目"数据存于街道指定环境、团队不持有原始数据"的定位一致，也是方案的差异化优势

## 三、推荐架构

```
按住说话
  ↓
录音（16kHz 单声道，opus/mp3）
  ↓
┌─ 主：自建 FunASR 服务（SenseVoice-Small）
│    · 输出：文字 + 情感标签 + 音频事件（咳嗽/哭声/背景音）
│    · 部署：一台 4 核 8G 云主机足够（老人端并发极低）
│
├─ 备：Qwen3-ASR-0.6B（流式，延迟更低）
│
└─ 兜底：云厂商 ASR（腾讯云/阿里云粤语引擎），仅当自建服务不可用时
  ↓
LLM 抽意图 → {类型, 紧急度, 置信度, 关键词, 原话摘要}
  ↓
置信度 ≥0.7 自动建单 / 0.4–0.7 追问 / <0.4 人工回放
```

**为什么不用 Whisper**：中文标点差、方言能力弱（粤语尚可，普通话方言差）、模型体积大、中文场景被 FunASR 系列全面超过。它是通用多语言的好选择，但不是中文方言场景的最优解。

## 四、一个被忽略的加分项：情感识别

SenseVoice 原生带**情感识别**（开心/愤怒/悲伤/中性）和**音频事件检测**（笑声、哭声、咳嗽、背景音乐）。

这对本项目意味着：

| 能力 | 可以做什么 |
|---|---|
| 情感异常 | 老人说"我没事"但声音发颤 → 标记为"表述与情绪不一致"，提示处置人多问一句 |
| 咳嗽/喘息 | 自动记为健康相关信号，进 L1 证据集 |
| 背景音 | 判断录音环境（电视开着 → 识别置信度自动降权） |

**这是方案的差异化点**——别人的语音识别只转文字，这套还能读情绪。

## 五、三个必须先知道的坑

### 坑 1：广西白话 ≠ 粤语

粤语模型（WenetSpeech-Yue 等）主要覆盖广府片。**南宁白话、桂柳话（西南官话）差异很大**，直接套粤语模型效果会掉。

你的调查里广西老人有 13 位，这个不能忽略。应对：
- 广西样本单独测，不混在粤语里报准确率
- 必要时用 Fun-ASR-Nano（7 方言）或云厂商的方言引擎

### 坑 2：老人的语音和测试集不是一回事

开源模型的 benchmark 用的是朗读语料、清晰录音。真实老人语音有：
- 气息弱、音量低
- 牙齿缺失导致咬字不清
- 语速慢、有长停顿
- 电视/收音机背景音
- 边说边想，句子不完整

**实际准确率一定低于报告值**，可能低 10–20 个百分点。所以追问机制不是"异常处理"，是常态流程。

### 坑 3：评价指标不该是字错率

你要的不是"逐字正确"，是"**分到正确的类**"。

老人说"我个头好晕"——识别成"我个头好润"不影响建单，因为意图还是"不舒服"。

所以测试时主指标用**意图分类准确率**，字错率（CER）只作参考。这个选择能省掉大量无谓的调优。

## 六、建议的验证方法

不要看 star 数做决定，用 30 条真实录音投票。

**测试集设计：**

| 维度 | 数量 | 说明 |
|---|---|---|
| 粤语（广府片） | 10 条 | 佛山/广州老人 |
| 广西白话/桂柳话 | 8 条 | 南宁等地老人 |
| 普通话（带口音） | 8 条 | 各地老人 |
| 含背景音 | 4 条 | 开着电视说 |

**每条内容**：模拟真实求助，10–30 秒，例如
- "我个头好晕，想起身又起唔到"
- "帮我买斤瘦肉，要新鲜的"
- "屋企个水龙头漏水，滴咗成日"

**对比三家**：FunASR(SenseVoice) / Qwen3-ASR-0.6B / 云厂商粤语引擎

**记录两个数**：CER（参考）+ **意图分类是否正确**（主指标）

30 条录音、半天时间，比看一百篇评测都准。

## 七、落地建议

| 阶段 | 做法 |
|---|---|
| 现在 | 先用云 API 打通链路（最快能跑），把"录音→识别→抽意图→建单"跑通 |
| 一周内 | 录 30 条测试集，跑开源模型对比 |
| 定稿前 | 自建 FunASR 服务替换云 API，音频不出本地，作为隐私卖点写进材料 |

> 先用云 API 不是妥协，是**先让链路跑起来**。识别引擎是可以替换的模块，别让它卡住整条流程。
